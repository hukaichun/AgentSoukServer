# Art credits

All artwork in this directory is **CC0 (public domain)**, by
[Luis Zuno (@ansimuz)](https://opengameart.org/content/tiny-rpg-forest),
from the *Tiny RPG Forest* pack. `UPSTREAM-LICENSE.txt` is the licence file
shipped inside that pack, unmodified.

CC0 requires no attribution. This file exists anyway, for two reasons.

**Provenance is the thing that is expensive to reconstruct.** A `.png` in a
repo carries no licence, and a year from now nobody can tell by looking
whether a given file may be redistributed. That is not hypothetical: the
AI Town checkout this project was evaluating ships an `assets/` folder
whose files come from four different sources under four different licences
— CC0, CC-BY 4.0, CC-BY-SA 3.0/GPL, and an itch.io pack — with nothing on
disk saying which file is which. One of them is ShareAlike. Copying that
folder wholesale would have been a licence gamble, which is why none of it
was copied.

**The author asked nicely.** "Credit is not required but appreciated."
